Where do I find the token?

A valid token starts with flx_ and is 40 characters long. In the Fluxer web app, press F12 → Network, reload the page, click a request to /api/... and copy the Authorization header value (it should start with flx_). It gives full access to your account: never share it. It is stored only in Stream Deck on this PC.
